smICA
single-molecule Image to Concentration Analyser¶


This repository provides software for calculating fluorophore concentrations from FLIM images stored in the PTU format (PicoQuant, Germany). The software allows the extraction of information about registered photons from the .ptu file, filtering them using statistical filters based on fluorescence decay time and autodetection of the region of interest (ROI), and finally creating a map of the absolute concentration of the fluorophore. The GUI is powered by Dear PyGui.
